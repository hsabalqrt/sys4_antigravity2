# تحديثات النظام المحاسبي والاشتراكات

تم الانتهاء من تنفيذ كافة متطلبات السيناريو المحاسبي وتطوير منطق النظام ليكون ذكياً ومؤتمتاً بالكامل.

## ما تم تنفيذه:

### 1. موديل الاشتراكات (Subscription Model)
- **الحساب التلقائي:** إضافة ميزة الحساب التلقائي لتاريخ الانتهاء (`end_date`) فور إنشاء الاشتراك بناءً على نوعه (أسبوعي/شهري/سنوي).
- **التحسينات:** تحسين حساب الأيام المتبقية وحالة الاشتراك.

### 2. الاستحقاق اليومي (Daily Accrual)
- **الأمر البرمجي:** تطوير الأمر `app:daily-subscription-accrual` ليقوم بخصم (مدين) مبلغ يومي من رصيد الاشتراكات "المؤخرة" فقط طالما أن مفعولها سارٍ.

### 3. الإيقاف الذكي والمنتهي (Daily Suspension)
تطوير الأمر `app:daily-subscription-suspension` ليعالج السيناريوهات المعقدة:
- **المقدم:** يتم إنهاء الاشتراك (`expired`) فور تجاوز `end_date` وفترة السماح.
- **المؤخر:** يتم الإنهاء فقط إذا انتهى الوقت وكان الرصيد سالباً وتجاوز فترة السماح.
- **السقف الائتماني:** يتم تجاهل الإيقاف التلقائي إذا كان خيار "السقف الائتماني" مفعلاً لدى العميل.

### 4. تطوير واجهة الإدارة (Filament UI)
- **العملاء:** إخفاء حقل "مدة التوقيف" تلقائياً عند تفعيل خيار السقف الائتماني لجعل الواجهة أكثر وضوحاً.
- **الاشتراكات:** تحديث زر "تجديد الاشتراك" ليكون مقيداً بالمديونية (لا يمكن تجديد اشتراك "مؤخر" لديه مديونية سالبة إلا بعد السداد، مع إظهار رسالة تنبيه).
